# MyChat App 

A real-time chat application built using the **MERN Stack**. Users can register, log in securely, and exchange messages in a simple and responsive interface.

##  Features

* User Registration & Login
* JWT Authentication
* Real-time Chat
* Responsive UI
* Secure Password Hashing
* Protected Routes

##  Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* Axios

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcrypt

##  Installation

### Clone the repository

```bash
git clone https://github.com/your-username/mychat-app.git
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
npm install
npm start
```

##  Environment Variables

Create a `.env` file inside the `backend` folder.

Example:

```
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
